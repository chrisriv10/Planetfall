# Planetfall v0.1.0

First public multiplayer MVP. Run across spherical planets, collect scrap, and keep your world intact while attacking rival worlds.

- Full-surface movement with radial gravity, jumping, burst, and grappling.
- Rooms for 2 to 6 participants, human-only multiplayer, and Play Solo with three bots.
- Scrap collection, rockets, heavy asteroids, and planet repairs.
- Destructible planets, seven-minute matches, overtime, spectator controls, and rematch voting.
- An authoritative Node.js/Socket.IO server with shared TypeScript contracts, client prediction, and snapshot interpolation.
- A Vite/Three.js client prepared for Cloudflare Pages, with the server prepared for Render.

Known limitations:

- Rooms exist only in memory and disappear when the server restarts or redeploys.
- Render Free may cold-start. If reconnect attempts run out, reload after the service wakes.
- Desktop keyboard and mouse are the supported input target.
